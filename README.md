# Windows 图标修复工具

一键修复 Windows 图标异常的批处理脚本。

## 功能

| 选项 | 功能 |
|---|---|
| 1 | 修复桌面快捷方式图标（重建图标缓存） |
| 2 | 修复开始菜单磁贴图标（重注册 UWP 应用） |
| 3 | 两项都修复 |

## 适用场景

- 换主板 / 换硬件后图标空白或错误
- 桌面快捷方式图标显示异常
- 开始菜单磁贴图标空白或错误

## 使用方法

双击运行 `图标修复工具.bat`，按提示输入选项编号（需要管理员权限，脚本会自动提权）。

## 原理

- **桌面图标修复**：删除 `IconCache.db`、`iconcache_*.db`、`thumbcache_*.db` 缓存后重启 `explorer.exe`
- **磁贴图标修复**：通过 `Add-AppxPackage -Register` 重新注册所有 UWP 应用
