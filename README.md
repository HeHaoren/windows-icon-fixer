# 🛠️ Windows 图标修复工具

> 换主板、换硬盘后图标全空白？开始菜单磁贴图标错乱？双击一下，30 秒搞定。

## 它能解决什么

| 症状 | 根因 | 修复选项 |
|---|---|---|
| 桌面快捷方式图标空白 / 错误 | 图标缓存（iconcache）失效 | `1` |
| 开始菜单磁贴图标空白 / 错乱 | UWP 应用注册状态损坏 | `2` |

**典型场景**：换主板、换硬盘、迁移系统后，Windows 的图标缓存与磁贴数据失效，导致大量图标显示为空白或默认图标。这个脚本一键重建，无需手动敲命令。

## 快速开始

1. 下载 `图标修复工具.bat`
2. 双击运行（自动请求管理员权限）
3. 按提示输入选项：
   - `1` 修复桌面快捷方式图标
   - `2` 修复开始菜单磁贴图标
   - `3` 两项都修

## 原理

- **桌面图标**：结束 `explorer.exe` → 删除 `IconCache.db` / `iconcache_*.db` / `thumbcache_*.db` → 重启 explorer 重建缓存
- **磁贴图标**：`Add-AppxPackage -Register` 重新注册所有 UWP 应用，重建磁贴图标资源

## 常见问题

**Q：会丢失数据吗？**
A：不会。删除的只是缓存文件，Windows 会自动重建。

**Q：磁贴修复要多久？**
A：1–5 分钟，取决于已安装的 UWP 应用数量。

**Q：需要联网吗？**
A：不需要，完全本地运行。

**Q：支持哪些系统？**
A：Windows 10 / 11。
